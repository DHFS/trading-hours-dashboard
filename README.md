## 项目简介

跨市场交易者最常遇到的困扰之一，是不断在脑中换算东京、首尔、伦敦、纽约的夏/冬令时与官方假期。**Trading Hours Dashboard** 采用 **一套引擎、两种形态** 的设计理念，让全球市场脉搏做到「打开即知」：

| 形态 | 适用场景 | 交互与视觉特征 |
| :--- | :--- | :--- |
| **瑞士极简联动矩阵** | 电脑 / 手机日常查盘 | 顶部 **4 大跨资产宏观锚**（美债10Y / 美元指数 / 离岸人民币 / VIX恐慌）+ 桌面端 4 列联动矩阵一屏尽览 **9 大市场**；统一 `00:00–24:00` 垂直激光时间轴（左侧过去时段自动压暗）；活跃市场高亮聚焦、休市自动降噪；顶部一键切换涨跌色 |
| **Float 桌面时钟** | iPhone / iPad 横屏摆台（PWA） | 全 9 市场统一的 **iOS StandBy "Float"** 纯黑 OLED 画布；巨大双拼色叠印圆体数字、冷白渐变双圆球冒号、按位差分滚动；交易看主力指数，休市看精确倒计时；移动端竖屏支持自由切换网页看板或竖屏查看 |

> **无缝互通**：在网页看板点击任意市场行（或顶部「桌面时钟」）即可无刷新进入该市场的全屏 Float 时钟；在全屏时钟轻触屏幕呼出控制条点击「返回看板」即可回到总览。

## 核心特性

- **北京时间基准（`Asia/Shanghai`）**：无论访问者身处哪个国家或设备时区，全站时间与倒计时均精确锁定北京时间。
- **9 大市场 × 7 种状态**：覆盖 **加密货币、黄金、日股、韩股、原油、A股、港股、欧股、美股**，精确区分 `交易中` / `午休` / `盘前`（含 A 股 `09:15–09:25` 与港股 `09:00–09:20` 集合竞价）/ `盘后` / `隔夜` / `周末休市` / `休市（法定假期）`。
- **4 大跨资产宏观风向标**：顶部条均分展示 **美债 10Y 收益率**、**美元指数**、**离岸人民币** 与 **VIX 恐慌指数**，辅助交易员一屏把握全球风险偏好与流动性锚点。
- **主次分明的时间轴设计**：24 小时进度条由逐分钟状态采样自动合并生成，激光时间轴精准对齐；激光线左侧历史时段自动压暗，交易中市场自带侧边高亮光条，休市行情主动降噪退后。
- **跨年动态夏令时 & 2026–2027 日历**：
  - 美股夏令时（3 月第 2 个周日 – 11 月第 1 个周日）与欧洲 / 英国夏令时（3 月最后周日 – 10 月最后周日）按年份动态推算，告别跨年硬编码；
  - 内置 2026–2027 年上交所、港交所（含半日市）、JPX、KRX、XETRA、NYSE（含提前收盘日）、CME COMEX 黄金及 ICE 布伦特原油休市日历，超范围自动提示。
- **全 9 市场 iOS StandBy "Float" 桌面时钟**：
  - 6 套精选配色（经典蔚蓝 + 5 套双拼波普预设）+ 随机配色，支持即时切换与持久化；
  - 独立冷白渐变双圆球冒号（静止不参与彩色混合）+ 低位向高位 40ms 交错差分滚动动画；
  - 运行时真实字体测宽拟合（`fitFloatStage()`）+ 左/右横屏灵动岛安全区双向适配，绝不截断溢出；
  - 内置 **夜间暗红护眼模式**、**省电静默模式**（暂停呼吸动画降低插电发热）、**每 3 分钟 ±4px OLED 防烧屏像素微移**；
  - 移动端竖屏进入全屏时钟时提供非阻断双选引导（可自由切换回移动端网页看板或直接竖屏查看）。
- **全大陆免 VPN 多源行情**：默认 **绿涨红跌**（支持一键切换红涨绿跌）；全部股指、黄金、原油与宏观指标均采用**中国大陆免 VPN 直连 CORS 接口**（腾讯 30 秒快轮询 + 华尔街见闻 VIX/美债/伦敦金 30 秒同频 + 东方财富兜底），BTC/ETH 走 Binance 现货公共镜像 WebSocket。
- **零构建零依赖**：纯原生 HTML / CSS / JS，无打包步骤、无后端服务器要求，开箱即可托管于任何静态服务器或 GitHub Pages。

## 快速上手

### 方式一：直接使用线上版

直接访问官方托管站点：**<https://dhfs.github.io/trading-hours-dashboard/>**

- 首页默认进入 **网页多市场看板**。
- 可通过 URL Hash 直达任意市场的全屏时钟，例如：
  `#crypto` · `#aShare` · `#hk` · `#jp` · `#kr` · `#eu` · `#us` · `#gold` · `#brent`

### 方式二：安装为 iPhone 桌面时钟（PWA）

1. 在 iPhone 上使用 **Safari** 打开 <https://dhfs.github.io/trading-hours-dashboard/>。
2. 点击底部工具栏的 **「分享」** 按钮 → 选择 **「添加到主屏幕」** → 确认添加。
3. 从桌面「交易时钟」图标启动（默认全屏进入 `#crypto`），横置手机即可摆台使用；竖屏状态下也可选择继续浏览移动端网页看板或竖屏查看时钟。

> [!TIP]
> **升级提示**：从早期版本升级至 `v0.12.1` 时，由于 `manifest.json` 的 `start_url` 已更新版本号（`?v=0.12.1`），请先长按删除旧的主屏幕「交易时钟」图标，再用 Safari 重新「添加到主屏幕」，即可绕过 iOS PWA 旧启动条目缓存。

#### 桌面时钟手势与快捷键速查

| 操作 | 效果 |
| :--- | :--- |
| **左右滑动**（或键盘 `←` / `→`） | 切换市场（`加密货币 → A股 → 港股 → 日股 → 韩股 → 欧股 → 美股 → 黄金 → 原油`） |
| **轻触屏幕** | 呼出底部玻璃态 **HUD 控制条**（4.5 秒无操作自动隐去；防误触设计，单击不再切走市场） |
| **HUD 控制条功能** | 6 套 Float 配色切换 · 随机配色 · 夜间红光 · 省电静默 · 锁定市场（防误滑） · 返回看板 |
| **键盘 `Esc`** | 退出全屏时钟，返回网页看板总览 |

### 方式三：本地运行与二次开发

无需安装 `npm` 包或任何构建工具，直接用任意静态 HTTP 服务器即可运行（浏览器 ES / Service Worker 需要 HTTP 环境，请勿直接双击 `file://` 打开）：

```bash
# 1. 克隆仓库
git clone https://github.com/DHFS/trading-hours-dashboard.git
cd trading-hours-dashboard

# 2. 启动本地静态服务（Python / Node 均可）
python3 -m http.server 8765
# 或：npx serve -l 8765

# 3. 浏览器打开
open http://localhost:8765
```

运行内置的时段与日历单元测试（需 Node.js ≥ 18）：

```bash
node tests/market-time.test.js
```

### 方式四：一键部署到你自己的 GitHub Pages

1. 点击仓库右上角 **Fork** 到你的 GitHub 账号。
2. 进入你的仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`，点击 **Save**。
4. 等待约 30 秒，即可通过 `https://<你的用户名>.github.io/trading-hours-dashboard/` 访问专属看板。

## 支持市场、时段与数据源

| 市场 | 交易所 | 交易时段（北京时间 UTC+8） | 行情主源 | 兜底 / 估算机制 |
| :--- | :--- | :--- | :--- | :--- |
| **加密货币** | Binance | 24/7 全年无休 | Binance 现货 WS (`BTCUSDT` / `ETHUSDT`) | Binance 现货 REST 镜像 |
| **A 股** | 上交所 / 深交所 | 集合竞价 `09:15–09:25`<br>交易 `09:30–11:30` · `13:00–15:00` | 腾讯财经（上证/深证/创业板） | 东方财富批量接口 |
| **港股** | HKEX | 开市前竞价 `09:00–09:20`<br>交易 `09:30–12:00` · `13:00–16:00`（含半日市） | 腾讯财经（恒生 / 恒生科技） | 东方财富批量接口 |
| **日股** | JPX | `08:00–10:30` · `11:30–14:30` | 东方财富 `stock/get`（日经225） | 腾讯日经 ETF（`sh513880`）涨幅估算 |
| **韩股** | KRX | `08:00–14:30`（连续） | 东方财富 `stock/get`（KOSPI） | 腾讯韩股 ETF（`hk03121`）涨幅估算 |
| **欧股** | XETRA / LSE | 夏令时 `15:00–23:30` · 冬令时 `16:00–00:30` | 东方财富（德国 DAX / 富时 100） | 东方财富 `stock/get` |
| **美股** | NYSE / Nasdaq | 夏令时盘前 `16:00–21:30` · 盘中 `21:30–04:00` · 盘后 `04:00–08:00`<br>冬令时顺延 1 小时；支持 `13:00 ET` 提前收盘日 | 腾讯财经（纳指 / 标普500 / 道指） | 东方财富批量接口 |
| **黄金** | CME COMEX / LBMA | 夏令时 `06:00–次日05:00`（`05:00–06:00` 维护）<br>冬令时 `07:00–次日06:00`（`06:00–07:00` 维护） | 腾讯外盘（COMEX `hf_GC` / 伦敦金 `hf_XAU`，30 秒刷新） | 华尔街见闻 `XAUUSD` / 东财 `futsseapi` & `push2delay` |
| **原油** | ICE / NYMEX | 夏令时 `08:00–次日06:00`（`06:00–08:00` 维护）<br>冬令时 `09:00–次日07:00`（`07:00–09:00` 维护） | 腾讯外盘（布伦特 `hf_OIL` / WTI `hf_CL`，30 秒刷新） | 东方财富 `futsseapi` → 东财 `push2delay` |
| **宏观风向标** | 跨资产基准 | 美债10Y · 美元指数 · 离岸人民币 · VIX恐慌 | 华尔街见闻（美债10Y / VIX 30 秒刷新）/ 东财（UDI / USDCNH） | 东方财富 `stock/get` |

> **说明**：
> - 全部传统股指、黄金、原油与宏观风向标数据源在中国大陆均**无需 VPN 可直接访问**；腾讯源与华尔街见闻源支持 30 秒快轮询，东方财富全量兜底轮询保持 5 分钟以规避风控。
> - BTC / ETH 现货采用 Binance 官方公共数据镜像（`data-stream.binance.vision` / `data-api.binance.vision`）。

## 年度日历维护与自定义

所有节假日配置集中在 [`js/data.js`](js/data.js)：

- `DATA_YEARS`：声明当前日历覆盖年份（当前为 `[2026, 2027]`）。若系统日期超出覆盖范围，看板顶部与全屏时钟右上角都会展示「日历需更新」提醒。
- `HOLIDAYS`：
  - `aShare`：A 股休市闭区间（需同步维护 `A_SHARE_HOLIDAY_NAMES`；注：2027 年条目当前基于国务院放假安排推演，待上交所 2026 年 12 月下旬官方公告发布后复核）。
  - `hk` / `hkHalf`：港股休市日与半日市。
  - `jp` / `kr` / `eu` / `us` / `usEarly` / `gold` / `brent`：日股、韩股、欧股（XETRA）、美股（含提前收盘日）、CME COMEX 黄金、ICE 布伦特原油休市日。
- 每次发布静态资源重大更新时，同步递增 [`sw.js`](sw.js) 中的 `CACHE_NAME` 与 [`manifest.json`](manifest.json) 中的 `start_url` 版本号。

## 版本日志

### `v0.12.1` (2026-11-28)
- **桌面大屏整数阶梯自适应**：网页看板（`≥ 1024px`）接入 `16px → 18px → 20px → 24px (2560×1440) → 28px → 32px` 整数像素阶梯放大与容器上下左右对称居中，兼顾笔记本、1080p、24 寸 2K 与 27 寸 4K 大屏观感。
- **macOS 4K 字体锐度优化**：桌面端优先使用系统原生光学字库（`-apple-system` / `SF Pro Text` / `PingFang SC` / `SF Mono`），移除强制削细的 `-webkit-font-smoothing: antialiased`，提亮暗底辅助文本对比度与字重，避免在 `2560×1440` 非整数缩放屏上发虚。
- **同级标的统一字号**：移除网页看板次行缩水覆写，确保同市场内部平级标的（如 BTC / ETH、COMEX / 伦敦金、布伦特 / WTI 等）标签、价格与涨跌幅严格同级对齐（不影响全屏 Float 桌面时钟主指数显示逻辑）。

### `v0.12.0` (2026-11-28)
- **瑞士世界时极简联动矩阵重构**：告别传统 Bento 卡片网格与冗余装饰，改用 4 列精密对齐矩阵，一屏尽览 9 大市场与统一 `00:00–24:00` 贯穿式激光时间轴；新增激光线左侧历史时段压暗遮罩。
- **信息降噪与视觉层级重塑**：消除顶栏「药丸汤」与行内状态/时段文案复读；为交易中与竞价/盘前/盘后增加高亮光条，休市行情主动收敛退后；解耦状态主色（`#14B8A6`）与上涨绿（`#22C55E`）。
- **市场扩充与跨资产宏观风向标**：
  - 新增 **欧股**（德国 DAX + 富时 100，随欧洲夏/冬令时换算）与 **黄金**（COMEX + 伦敦金，遵循 CME 23 小时连续交易与维护窗口）；
  - 原油分类整合 **布伦特** 与 **WTI** 双原油标的；
  - 补充 **A 股（09:15–09:25）** 与 **港股（09:00–09:20）** 集合竞价微状态；
  - 顶部新增 4 大纯宏观锚：**美债10Y**、**美元指数**、**离岸人民币**、**VIX恐慌指数**（均支持中国大陆免 VPN 直连）。
- **移动端竖屏体验优化**：取消强制横屏锁死提示，竖屏打开桌面时钟时提供「切换到移动端网页看板 / 仍然竖屏查看时钟」自由选择权（附 32 项 Node 单元测试）。

### `v0.11.1` (2026-11-28)
- **布伦特原油数据源大陆直连化**：移除在中国大陆不开 VPN 会被阻断的 `fstream.binance.com` / `fapi.binance.com`（`BZUSDT`），改用真实 ICE 布伦特原油期货三源自动降级：**腾讯外盘期货 `hf_OIL`（主源）→ 东方财富独立期货接口 `futsseapi`（备源 1）→ 东方财富 `push2delay`（备源 2）**。
- **腾讯源 30 秒快轮询**：将腾讯接口（A 股 / 港股 / 美股股指 + 布伦特原油）拆分为 30 秒独立快轮询，东财全量兜底维持 5 分钟防风控，兼顾实时性与稳定性，消除无 VPN 环境下的后台网络报错。
