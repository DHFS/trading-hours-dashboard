# 交易时段看板（北京时间）

一个「打开即知」的全球交易时段看板。以北京时间为基准，实时显示 A股 / 港股 / 日经 / 美股 / 加密货币 的开休市状态、倒计时与行情，并正确处理节假日与美股夏令时。

## 特性
- 北京时间基准（`Asia/Shanghai`），与访问者所在时区无关
- 5 大市场实时状态：交易中 / 午间休市 / 盘前 / 盘后 / 隔夜休市 / 周末休市 / 节假日休市
- 距下次开盘/收盘倒计时
- 实时行情：东方财富（指数点位）、Binance（BTC/ETH），红涨绿跌
- 节假日内置（2026 年，来源：上交所 / 港交所 / JPX / NYSE 官方日历）
- 美股自动切换夏令时 / 冬令时，并处理提前收盘日
- 纯静态，无后端依赖，可直接部署 GitHub Pages

## 文件结构
```
index.html   页面结构
style.css    样式（暗色主题）
app.js       时段判定 / 倒计时 / 行情 / 渲染逻辑
data.js      节假日数据与市场配置
```

## 数据更新
节假日数据集中在 `data.js` 顶部的 `HOLIDAYS` 对象中，按市场分类：

- `aShare`：A股休市区间（`[起,止]` 闭区间，含周末）
- `hk`：港股休市日 + `hkHalf`：港股半日市
- `jp`：日经/东交所休市日
- `us`：美股全休市日 + `usEarly`：美股提前收盘日

每年末需根据各交易所官方公告更新下一年的数据，并同步修改 `DATA_YEAR`。
若当前日期超出 `DATA_YEAR` 覆盖范围，页面顶部会提示「需更新数据」。
